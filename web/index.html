How MCRC works

Four reversible stages. Every step can be undone.

1

Clockface swap

The alphabet splits into two rows: inner A–L, outer N–Y. M and Z stay in the centre.

The key gives each row a slide amount:

  • Inner slide = hour
  • Outer slide = minute ÷ 5

For each letter: slide along its row by that amount, then swap straight across.

Example at 3:20 (slides 3 and 4): Q at outer col 4 → slide +4 → col 8 → swap → inner H.

12 × 12 = 144 possible keys. This is the only stage where the key matters.

2

Mirror the letters

Reverse the string. That's it. DHRRA becomes ARRHD.

3

Reverse cipher (letters → numbers)

Use an inverted alphabet chart: A = 25, B = 24, …, Z = 00. Each letter becomes a two-digit code joined by dashes.

4

Swap consecutive number pairs

Swap every adjacent pair: (a, b) → (b, a). Odd last code stays.

Example: 21-05-05-14-18 → 05-21-14-05-18.

4

Undo stage 4 — swap the pairs again

Take the ciphertext and swap every adjacent pair a second time. Swap-pairs is its own inverse: (a,b) → (b,a) → (a,b). Odd last element still stays put. 05-21-14-05-18 becomes 21-05-05-14-18.

3

Undo stage 3 — numbers back to letters

Same chart as stage 3 forward (A=25, B=24, …, Z=00), read the other way. Each two-digit code becomes its matching letter. 21-05-05-14-18 becomes EUULH.

2

Undo stage 2 — unflip the letters

Reverse the string again. Mirror is its own inverse. EUULH becomes HLUUE.

1

Undo stage 1 — unswap with the key

For each cipher letter, slide backwards by the appropriate amount, then swap across.

Slide source flips in reverse:

  • Inner cipher letter → slide left by minute ÷ 5, swap up
  • Outer cipher letter → slide left by hour, swap down

Example at 3:20: H at inner col 8 → slide −4 → col 4 → swap up → Q. So HLUUE → QUEEN.

Wrong key gives garbled letters, not an error.
